# Number-guessing-project
The above submitted project is about guessing a number    


1. HOW DOES THIS WORK :
   *You start the game.
   *you will be asked to guess a number.
   *the game will tell the limits.
   *you will play until you win.

2. PROCESS:
   *you will be informed if your number is greater or lower.
   *accordingly you have to change.
   *this will take place till you get correct number.

3. END:
   *When the guess will be correct the game will end.
    *you can play again if you want .
